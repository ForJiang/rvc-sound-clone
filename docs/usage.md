# 使用说明

RVC Sound Clone 是一个纯静态网页：所有推理都在浏览器里完成，音频与模型不会上传到任何服务器。

## 1. 本地运行

```bash
# 任意静态服务器都可以，这里用 Python 自带模块
python3 -m http.server 8080

# 打开 http://127.0.0.1:8080
```

注意：必须通过 `http://` 或 `https://` 访问，直接双击 `index.html`（`file://` 协议）会因为浏览器安全策略无法运行。

## 2. 准备原始音频

三种方式：

- **麦克风录制**：在安静环境录制 5～30 秒单人说话。录音时下方电平条应有明显起伏但不要顶满。点一下圆形麦克风按钮开始，按钮会先显示「正在请求麦克风权限…」，浏览器弹授权框通过后才变成「录制中…」并开始计时；再点一次停止，音频自动加入队列。**最长录 1 分钟**，到点会自动停止，最后 10 秒计时器转成黄色提醒。
- **上传文件**：支持 wav / mp3 / ogg / m4a / aac / flac / webm / opus，单个文件 ≤ 50MB，可一次拖入多个批量转换。
- **示例音频**：预留入口，仓库不内置人声音频。

建议原始音频：单人、无背景音乐、无混响、无明显削波。原始音频质量直接决定结果质量。

## 3. 选择音色

- 第一次使用需要下载**基础模型**（HuBERT + RMVPE），在「模型库 → 基础模型」点击下载。
- 音色模型在「模型库 → 音色模型」下载社区模型，或「本地导入」拖入自己的 `.pth` + `.index`（本地服务引擎）或 `.onnx` 包（浏览器引擎）。

## 4. 参数

| 参数 | 说明 | 建议 |
| --- | --- | --- |
| 变调（半音） | 整体音高平移 | 男→女 +12，女→男 -12 |
| 索引强度 | 检索索引权重 | 0.6～0.8 |
| 清音保护 | 保护 s/sh/f 等清音 | 0.33 |
| 音量包络混合 | 保留原始音量起伏 | 0.2～0.3 |
| 中值滤波半径 | 音高平滑 | 3 |

## 5. 导出

- 单个结果：点「下载 WAV」。
- 多个结果：点「打包下载 ZIP」，浏览器内直接打包，无需上传。

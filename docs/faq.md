# 常见问题

### 页面一直卡在加载
用 `http://127.0.0.1:8080` 或你的 Pages 地址访问，不要用 `file://`。另外浏览器首次运行需要从 CDN 拉取 ONNX Runtime，网络不通时可以改用本地服务引擎。

### 麦克风按钮点了没反应 / 提示录音失败
按顺序排查：

1. **地址是不是 `http://` 且不是 localhost** —— 浏览器只在 HTTPS 或 localhost 下开放麦克风权限，GitHub Pages 是 HTTPS 所以没问题，`file://` 打开一定不行；
2. **地址栏左侧的权限图标**是否被设成了「禁止」，去浏览器设置里改成允许后刷新页面；
3. **系统设置**里是否给浏览器授予了麦克风权限；
4. 提示「被其他程序占用」时，关掉正在用麦克风的会议/录屏软件再试；
5. 提示「未检测到设备」则换一个输入设备或插上麦克风。

按钮点下去会先显示「正在请求麦克风权限…」，这段时间是浏览器在等你在弹窗里授权；授权通过才会变成「录制中…」并开始计时。最长录 1 分钟，到点会自动停止并把音频加入队列。

### 提示「缺少模型文件 xxx.onnx」
基础模型或音色模型没有下载/导入完整。到「模型库」查看状态，四个 ONNX 文件（hubert / f0 / speaker / generator）缺一不可。

### 转换很慢或页面卡住
浏览器引擎是 CPU/WASM 或 WebGPU 计算，受设备性能限制。建议：把音频控制在 20 秒以内、关掉其他占用 GPU 的页面、或切换到本地服务引擎（有显卡的机器会快一个数量级）。

### 结果有金属音、机械音或明显杂音
1. 降低索引强度到 0.6 左右；
2. 中值滤波半径调到 3～5；
3. 换一段更干净的原始录音；
4. 确认变调方向正确（男→女 +12，女→男 -12）。

### 本地服务引擎连不上
1. 先启动 `python3 server/bridge.py`；
2. 网页「设置 → 本地服务引擎 → 测试连接」看具体报错；
3. 桥接层默认转发到 `http://127.0.0.1:5555`，即官方 RVC WebUI 的 API；用 `--upstream` 可改。

### 模型下载到一半失败了
「模型库」中点取消或重新下载即可，IndexedDB 里不会留下半成品。若浏览器提示存储空间不足，请到「设置 → 模型缓存」清空后重新下载需要的模型。

### 我的音频存在哪里
只存在你自己浏览器的 IndexedDB。清空浏览器站点数据即彻底删除，服务端没有任何副本。

### 支持实时变声吗
当前版本是文件/录音转换。实时链路（AudioWorklet + 流式推理）在路线图里，欢迎提 PR。

### 为什么仓库里没有内置音色模型
音色模型涉及本人声纹与第三方授权，仓库只提供工具与基础模型，音色一律由使用者自行导入并确保已获授权。
